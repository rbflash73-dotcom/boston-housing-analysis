# Boston Housing Statistical Analysis

Final project for **Statistics for Data Science with Python** (IBM, Coursera).

The notebook [`FinalProject_Boston_Housing.ipynb`](FinalProject_Boston_Housing.ipynb) analyzes U.S. Census Service housing data for Boston, MA, to answer four questions for a housing agency's management team:

1. Is there a significant difference in median home value for houses bounded by the Charles River? (t-test)
2. Do median home values differ by the proportion of owner-occupied units built before 1940? (ANOVA)
3. Is there a relationship between nitric oxide concentration and the proportion of non-retail business acres per town? (Pearson correlation)
4. What is the impact of an additional weighted distance to the five Boston employment centers on median home value? (Linear regression)

The notebook includes data exploration, five visualizations with interpretations, the hypothesis tests, and a summary of findings.
